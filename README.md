# Cámara de Comercio Digital de Honduras (CCDH)

Bienvenido al repositorio del sitio web oficial de la **Cámara de Comercio Digital de Honduras**. Este proyecto es una landing page moderna diseñada para presentar la misión, visión y propuesta de valor de la organización, promoviendo la innovación digital y el ecosistema blockchain en la región.

## 📋 Descripción

Este sitio web sirve como punto de entrada para empresas, emprendedores y profesionales interesados en la economía digital en Honduras. Ofrece información sobre quiénes somos, nuestra propuesta de valor, aliados estratégicos y medios de contacto.

## ✨ Características

-   **Diseño Moderno y Responsivo**: Adaptado a dispositivos móviles y de escritorio.
-   **Animaciones Interactivas**: Uso de GSAP para efectos visuales atractivos y transiciones suaves.
-   **Navegación Intuitiva**: Menú de navegación claro y secciones bien definidas (Inicio, Quiénes Somos, Propuesta, Afiliados, Contacto).
-   **Formulario de Contacto**: Interfaz para que los interesados puedan comunicarse fácilmente.

## 🛠️ Tecnologías Utilizadas

-   **HTML5**: Estructura semántica del contenido.
-   **CSS3**: Estilos personalizados y diseño responsivo (`css/style.css`).
-   **JavaScript**: Lógica de interacción y manipulación del DOM (`js/main.js`).
-   **GSAP (GreenSock Animation Platform)**: Biblioteca para animaciones de alto rendimiento.
-   **Fuentes**: Inter y Urbanist (Google Fonts).

## 📂 Estructura del Proyecto

## 🚀 Cómo Usar

1.  **Clonar el repositorio**:
    ```bash
    git clone <URL_DEL_REPOSITORIO>
    ```
2.  **Abrir el proyecto**:
    Navega a la carpeta del proyecto y abre el archivo `index.html` en tu navegador web preferido.

    O si usas una extensión como Live Server en VS Code, puedes iniciar el servidor para ver los cambios en tiempo real.
